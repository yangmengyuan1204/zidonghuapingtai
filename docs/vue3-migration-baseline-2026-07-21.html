1.3 视图与跳转

机制：自定义 state.view 字段 + renderShell() 全量重渲染 + renderCurrentView() 派发。无 hash 路由、无 history 路由。

视图 key标签渲染函数adminOnly备注
dashboard工作台总览renderDashboard()否默认视图
projects项目空间renderProjects()否含环境、账号档案子区
apiCases接口用例库renderApiCases()否—
dataScripts数据工厂renderDataScripts() / renderDataScriptEditor()否由 state.factory.editing 决定

跳转方式：侧边栏 #mainNav click 事件代理 → 修改 state.view → renderShell()。代码内主动跳转（如执行后跳 records）也是同样方式。

1. 登录页

进入方式：应用启动时 bootstrap() 检测 state.token 为空 → 调 renderLogin()；任何接口返回 401 时清除 token 后回到此页；用户点击顶部"退出"按钮

页面初始化

  • 不调用任何接口
  • 读取 localStorage：savedUsername → 填入账号框；savedPassword → atob 解码后填入密码框；两者同时存在时"记住密码"勾选默认勾上

可交互元素

元素调用函数调用接口修改 state写 localStorage其他行为最终页面变化
"登录"按钮（表单 submit） 内联 async submit handler POST /api/auth/login
body: { username, password }		 成功：state.token、state.user 写 token；勾选"记住密码"时写 savedUsername + savedPassword（btoa 编码）；未勾选则移除这两个键 toast 失败时弹后端 detail（两次：api 内 + catch 内）
不禁用按钮
不打开弹窗		 成功 → renderShell() 进入 dashboard
失败 → 留在登录页，输入框保留
注意：登录页无禁用按钮逻辑，登录期间用户可重复点击提交。

汇总 · Vue 重构必须保留的行为

轮询点（7 处，必须保留语义）

  • UI 用例可视化执行：setInterval 1s 调 GET /api/ui-executions/{run_id}，状态∈{passed,failed} 或异常或弹窗关闭时停止
  • UI 用例录制：setInterval 1s 调 GET /api/ui-record/sessions/{id}/events，弹窗关闭时停止
  • 实时录制（liveRecorder）：setInterval 1s 调 GET /api/browser-record/sessions/{id}/events，弹窗关闭时停止 + DELETE 清理
  • 数据智能体：setTimeout 1s 递归调 GET /api/data-scripts/agent/sessions/{id}，状态∈{succeeded,failed,blocked,cancelled} 时停止；工具调用子记录通过 kind=data_agent_tool 单独查询
  • 需求验证中心：setTimeout 1.2s 递归调 GET /api/requirement-verification/runs/{id}，状态∈{succeeded,failed,blocked,cancelled} 时停止
  • 功能测试执行进度：SSE 优先（GET /api/functional-executions/{job_id}/events），EventSource 失败回退 setInterval 1s 调 GET /api/functional-executions/{job_id}
  • 需求验证 v2 边测边教：setInterval 1s 调 GET /api/requirement-verification/v2/runs/{id}/teach-status，暂停/继续/取消按钮控制

SSE 端点（1 处，必须保留语义）

  • 功能测试执行进度：GET /api/functional-executions/{job_id}/events，Content-Type: text/event-stream，前端 EventSource 监听 message 事件，失败自动降级为 1s 轮询

其余所有"看起来像流式"的功能（UI 可视化执行、UI 录制、实时录制、数据智能体、需求验证）均无 SSE，全部用 setInterval/setTimeout 轮询。

localStorage 写入键（14 个，必须保留持久化语义）

  • token：登录成功写入，退出登录清除，每次 api() 请求自动带上 Authorization: Bearer
  • projectId：切换项目时写入，bootstrap 时读取恢复选中项目
  • theme：暗色/亮色切换写入，bootstrap 时读取应用
  • savedUsername：登录页"记住我"勾选时写入（明文），取消勾选时清除
  • savedPassword：登录页"记住我"勾选时写入（atob 编码，非加密），取消勾选时清除
  • FLOW_STORAGE_KEY（data_script_flows）：数据脚本 flow 列表本地草稿，编辑器自动保存
  • dataFactoryAgentSessionId：数据智能体会话 ID（实际写入 sessionStorage，非 localStorage，刷新页面后恢复对话）
  • req_verification_draft：需求验证中心表单草稿（材料文本、测试点等）
  • req_pack_filter：需求包列表筛选状态
  • ui_case_filter：UI 用例列表筛选状态
  • api_case_filter：接口用例列表筛选状态
  • record_filter：执行报告筛选状态
  • ai_config_draft：全局 AI 配置草稿（provider/base_url/model/api_key 未保存时）
  • quick_start_last_choice：快捷启动栏上次选择

sessionStorage 1 个：dataFactoryAgentSessionId。

1. 目标与范围

本轮唯一目标是在 Vue 项目中建立可供后续 Base Components 和 Shell 消费的 Frontend V2 Foundation，不迁移业务页面，也不改变现有业务逻辑。

范围完成状态说明
Foundation Token完成颜色、排版、间距、圆角、阴影、动效、图标、控件、布局和 z-index。
Semantic Token完成文字、表面、边框、动作、反馈和状态语义。
Component Token完成Button、Input、Shell、Table、Modal、Toast 等后续组件入口。
Scoped Reset / Base完成全部限定于 V2 根命名空间。
Base Components / Shell 改版未开始属于 Phase 5.2 / 5.3，因此本阶段没有明显视觉变化。

3. Token 架构

Foundation Token（原始值）
        ↓
Semantic Token（只引用 Foundation）
        ↓
Component Token（只引用 Foundation / Semantic）
        ↓
Phase 5.2+ Base Components / Shell / Business Views
层级职责约束
Foundation保存 Prototype 对应的原始设计尺度和色值。所有变量以 --v2-* 命名；不引用上层 Token。
Semantic表达 primary、surface、danger、focus 等产品语义。只能引用 Foundation。
Component为后续 Button、Input、Sidebar、Table、Modal、Toast 提供稳定接口。只能引用 Foundation 或 Semantic；本阶段不创建 Vue 组件。

4. 命名空间与 legacy 隔离证明

  • V2 CSS 不包含共享 :root。
  • V2 Token 全部挂载在 .frontend-v2 和 .frontend-v2-portal。
  • Reset/Base 的所有规则均从上述命名空间开始。
  • Vue 的 #app 直接获得 .frontend-v2，未新增无意义 DOM。
  • static/index.html 未引入 V2 CSS，递归扫描 static/ 未发现 V2 CSS 引用。
  • 浏览器中 legacy 根节点读取到的 --v2-* 数量为 0。
  • legacy CSS 与 Prototype 在实施前后的 SHA256 一致。

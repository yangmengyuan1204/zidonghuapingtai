# Frontend V3 Workbench Redesign — Codex UI Reference Pack

## Highest-priority rule

SOURCE CODE DEFINES FUNCTIONALITY. UI IMAGES DEFINE VISUAL APPEARANCE ONLY.

- Do not add any business feature, button, field, route, state, permission, API call, or workflow that does not exist in the current source code.
- Do not remove, merge, hide, rename, or change any existing business feature, button, field, route, state, permission, API call, or workflow.
- Do not modify backend logic, database structure, API contracts, permission rules, or business behavior.
- If a UI image conflicts with source code, preserve the source-code behavior and adapt only the visual styling.
- Generated-image sample text/data may be illustrative; never infer business requirements from it.
- The redesign target is the light workbench visual direction: approximately 220px light gray-blue sidebar, approximately 56px top bar, cool gray-blue workspace, white work panels, cobalt-blue primary actions, ~8px radii, thin borders, minimal shadow, no gradient/glass/heavy shadow.

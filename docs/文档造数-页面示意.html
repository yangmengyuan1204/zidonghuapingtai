系统怎么拼（给你看规则，不是黑盒）

1. 目录顺序：公共 → 前台 → 后台 → 工厂

2. 名称：登录最前，创建/提交在中，查金额靠后

3. 字段依赖：有 token / order_id 的接到需要它们的接口前面

拼不准的接口放在「未入链」，你可以在配置页补勾。承诺是建议链，不是一次猜对全部业务。
